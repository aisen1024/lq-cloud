# LQ_Cloud

#### Description
灵雀生态，打造成本最小化开发以及快捷交付，以redis为基础构建高性能架构，打造新一代中小企业的微服务架构。
主要功能：常规的redis轻量级操作、分布式锁、微服务的注册以及发现、消息总线， 延迟消息队列MQ、顺序消息队列MQ、去重消息队列MQ，支持dubbo RPC和 SpringCloud生态体系。
